# TaskFlow — Productivity Dashboard

TaskFlow is a responsive productivity dashboard built using HTML, CSS, and vanilla JavaScript.

## Features

- Add tasks with Low, Medium, or High priority
- Mark tasks as completed
- Delete individual tasks
- Filter All / Active / Completed tasks
- Clear all completed tasks
- Automatic task statistics
- Completion percentage and progress bar
- Dark mode
- LocalStorage persistence
- Responsive design for mobile, tablet, and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Browser LocalStorage

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Add tasks and test the dashboard.

No backend or external libraries are required.
